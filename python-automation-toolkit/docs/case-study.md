# Case Study

## Problem

I wanted Python in the portfolio as a practical supporting skill, not as a random detour.

## Solution

I started with a focused automation toolkit that turns small workflow tasks into clean CLI utilities.

The first version already includes:

- a file organizer
- a README generator
- a CSV cleaner for job application tracking data

## Why It Matters

This project shows:

- Python scripting ability
- automation mindset
- clear repository structure
- reusable tooling habits
