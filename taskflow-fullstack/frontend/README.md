# TaskFlow Frontend

## Overview

This is the React frontend foundation for `taskflow-fullstack`.

The current slice establishes:

- route structure
- layout shell
- dashboard page shell
- projects page shell
- board page shell
- auth screen shells

## Current Direction

The frontend is being built to mirror the backend product modules:

- auth
- dashboard
- projects
- tasks / board
- profile
