# GitHub Profile Plan

## Goal

Turn your GitHub profile into a recruiter-friendly landing page that supports your portfolio ecosystem and reinforces your target role:

Fullstack Developer | Java Spring Boot | React | PostgreSQL | AI-assisted Development

## Profile Strategy

Your GitHub profile should communicate three things in under 30 seconds:

1. what roles you are targeting
2. what stack you are strongest in
3. which repositories prove that claim

## Profile README Structure

Create a profile README in your special GitHub profile repository with this structure:

```md
# Hi, I'm Ruhat Karatas

Fullstack Developer focused on Java, Spring Boot, React, PostgreSQL, and AI-assisted development.

## About Me
## Tech Stack
## Featured Projects
## What I'm Building
## Blog / Notes
## Contact
```

## Recommended Profile Headline

Use a short, consistent headline across GitHub, LinkedIn, and your portfolio:

**Fullstack Developer | Java Spring Boot | React | PostgreSQL | AI-assisted Development**

## Featured Repositories To Pin

Pin these six repositories once they are presentable:

1. `portfolio-website`
2. `taskflow-fullstack`
3. `spring-employee-management-api`
4. `spring-security-jwt-auth`
5. `commercecore-admin`
6. `ai-job-application-tracker`

## Repository Description Standards

Every repository should have:

- a one-line description
- relevant topics
- a clean README
- no broken setup steps

### Example descriptions

- `portfolio-website`: Personal developer portfolio built with React, TypeScript, and Tailwind CSS.
- `spring-employee-management-api`: REST API for employee, department, and position management using Spring Boot and PostgreSQL.
- `spring-security-jwt-auth`: Spring Security JWT authentication and role-based authorization API.
- `taskflow-fullstack`: Fullstack project and task management application with Spring Boot, React, and PostgreSQL.
- `commercecore-admin`: E-commerce admin dashboard for product, order, and stock management.
- `ai-job-application-tracker`: AI-assisted job application tracker with Spring Boot, React, PostgreSQL, and AI API integration.

## Visual Quality Rules

1. Keep the profile clean and readable.
2. Do not overuse badges.
3. Avoid cluttered auto-generated stats if they distract from the projects.
4. Prioritize repository quality over decorative profile widgets.
5. Keep naming, branding, and descriptions consistent across platforms.

## GitHub Hygiene Checklist

Use this checklist for every repository before making it public:

- README is complete
- `.env.example` exists
- screenshots are included if applicable
- repository description is set
- repository topics are set
- no sensitive data is committed
- setup steps work
- demo link works if present
- commit history looks intentional

## Success Criteria

Your GitHub profile is successful when:

- a recruiter can understand your role target quickly
- your pinned repositories support your headline
- each repo looks intentional and complete
- your profile and portfolio tell the same professional story
